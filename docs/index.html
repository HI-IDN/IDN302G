Upplýsingaverkfræði IÐN302G

Höfundur

Helga Ingimundardóttir

Velkomin í námsefni námskeiðsins Upplýsingaverkfræði IÐN302G við Háskóla Íslands. Tilgangur námskeiðsins er að undirbúa nemendur fyrir nám og störf sem krefjast öflunar, meðhöndlunar, greiningar og framsetningu upplýsinga.

Námsefnið skiptist í eftirfarandi hluta:

AthugasemdSQL grunnatriði

Grundvöllur gagnagrunnsvinnslu: uppsetning SQLite, grunnfyrirspurnir, töflur, samlagningu og flokkun, NULL-gildi, undirfyrirspurnir, gagnaheildleiki, innflutningur og útflutningur.

AthugasemdSQL framhald

PostgreSQL, UNION, JOIN, VIEW, föll, CTE (Common Table Expressions) og PostGIS fyrir landfræðileg gögn.

AthugasemdMyndræn framsetning

Gagnafrásögn, gagnvirk gröf (Plotly), gagnvirk kort (Leaflet), mælaborð (Shiny/Flexdashboard) og góðar og slæmar venjur í sjónrænni framsetningu.

ÁbendingReglulegar segðir (regex) — kemur

Leit og vinnslur á textagögnum með reglulegar segðir í R og öðrum tólum.

ÁbendingGitHub og skjalastjórnun — kemur

Útgáfustjórnun með Git og GitHub: geymsla, útibú, samþætting, kóðarýni og vinnuflæði.

ÁbendingGervigreind sem hjálpartæki — kemur

Notkun gervigreindar (LLM) við forritun, kóðarýni og gagnagreiningu á ábyrgan hátt.

Hæfniviðmið

Nemandi öðlast hæfni í að:

  • afla, meðhöndla, greina og setja fram gögn og upplýsingar
  • beita fyrirspurnarmálinu SQL við úrvinnslu gagna (SQLite og PostgreSQL)
  • nota reglulegar segðir (regex) til að leita í og vinna úr textagögnum
  • setja fram gögn á sjónrænan hátt með gröfum, kortum og mælaborðum
  • nota GitHub til að geyma, deila og fylgjast með breytingum á kóða
  • beita skjalastjórnun og vinnuflæði forritunar (skrár, möppur, útgáfustjórnun)
  • framkvæma kóðarýni og skrifa skýran og læsilegan kóða
  • nýta sér gervigreind sem hjálpartæki við forritun og gagnagreiningu

Námsefni

Hvert kafli inniheldur útskýringar, sýnidæmi og æfingar — farðu í gegnum það í þeirri röð sem það birtist í hliðarstikunni til vinstri.

Gagnaskrárnar sem notaðar eru í sýnidæmum og æfingum eru í data/ möppunni í gagnageymslunni (e. repository).

Framlag og endurgjöf

Villur og ábendingar eru vel þegnar — sjá README fyrir leiðbeiningar um hvernig á að tilkynna villur eða leggja til breytingar.
