University of Iceland. Published at [hi-idn.github.io/IDN302G](https://hi-idn.github.io/IDN302G).

## Language

- All readable content is written in **Icelandic**
- File and folder names are in **English**
- Do not add English prose to `.qmd` or `.md` content files

## Content guidelines

- This is a Quarto book — source files are `.qmd` and `.md`
- Edit source files under `src/`
- Do not modify files in `docs/` by hand — that is the rendered output, generated by Quarto from `src/`
- Templates in `src/templates/` are for students to copy into their own repos; keep them generic
  (Quarto copies them into `docs/templates/` automatically via `resources:` in `_quarto.yml`)
- The `_quarto.yml` controls navigation — update it when adding or renaming pages

## Building and publishing

Use the `Makefile` in the repository root (`public/`):

- `make` — render only changed pages (fast, for content edits)
- `make full` — full render; required after `_quarto.yml`, `styles/*.scss`, or any
  structural/chapter change, because those affect the sidebar/theme on **every** page
- `make preview` — live preview with auto-reload while editing
- `make clean` — remove `docs/` and derived cache

**Before pushing to GitHub, this exact order is required:**

1. Run **`make full`** — never commit `docs/` from a partial or single-file render;
   the rendered site must be internally consistent (sidebar, cross-links, templates).
2. **Verify the built site works** — start the preview server, confirm the affected
   pages render correctly and there are no console/render errors. Do not skip this.
3. Only after verification, **commit the `docs/` folder together with the `src/` changes**
   and push to GitHub. `docs/` is the GitHub Pages output, so `src/` and `docs/` must
   always be committed in sync — never push `src/` changes without the matching rebuilt
   `docs/`, and never push a `docs/` that has not been verified.

Committing and pushing happens **only when the user explicitly asks**; do not push on your own.
