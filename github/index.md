## Hvað er Git og GitHub?

**Git** er dreift útgáfustjórnunarkerfi (e. *version control system*) sem heldur utan um
breytingar á skrám yfir tíma. **GitHub** er vefþjónusta sem hýsir Git-gagnageymslur og auðveldar
samstarf og deilingu á kóða.

## Efni sem verður farið yfir

- Uppsetning og grunnstillingar Git
- Geymsla og útibú (`init`, `clone`, `branch`, `checkout`)
- Breytingar og samþætting (`add`, `commit`, `push`, `pull`, `merge`)
- GitHub: geymsla, issues, pull requests
- Kóðarýni (*code review*) og vinnuflæði í teymi
- Skjalastjórnun: möppur, skrár og README
- Dæmi úr námskeið
